Interaction Model

群、用户和沙箱各司其职。

群聊是入口，沙箱是执行现场，Coke Codex Web 是可视化工作台。团队成员可以继续在群里追问， 也可以打开浏览器进入同一个沙箱查看文件树、预览报告和接管项目。

群绑定沙箱 适合多人围绕同一个任务持续协作，减少“到底是谁的沙箱”的歧义。
组织身份映射 飞书、钉钉用户后续可通过统一认证映射到 Coke Codex 账号和权限。
产物优先 聊天卡片展示 HTML、Word、PPT、Markdown 等最终交付物，长内容留在沙箱。
浏览器续作 点击链接打开完整 Web 沙箱，保持和桌面端一致的项目、聊天、文件预览体验。
